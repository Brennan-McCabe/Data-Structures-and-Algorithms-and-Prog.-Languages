Variable Scope

To demonstrate local and global variables, I'll calculate the circumference of a circle where pi is a global variable and the radius is declared as a local variable.

Python:

	GLOBAL_PI = 3.1415

	def calculate_circ(radius):
		local_circ = 2 * GLOBAL_PI * radius
		return local_circ

Java (No true globals)

	public class GeometryMath{
		static final double GLOBAL_PI = 3.1415;
		public static double calculateCirc(double radius){
		double localCirc = 2 * GLOBAL_PI * radius;
		return localCirc;
		}
	}

C++ & C:

	const double GLOBAL_PI = 3.1415;

	double calculateCirc(double radius) {
		double localCirc = 2 * GLOBAL_PI * radius;
		return localCirc;
	}

PERL:

	our $GLOBAL_PI = 3.1415;
	sub calc_circ {
		my $radius = shift;
		my $local_circ = 2 * $GLOBAL_PI * $radius;
		return $local_circ;
	}

OOP

Object Oriented Programming

To demonstrate OOP in the various languages, I'll create a Rectangle class initialized with a height and width and calculate its area. Note that some languages are built for OOP and some are not. In C specifically, there are no classes, but we can replicate classes by building structs. PERL also handles OOP in an unusual way requiring you bless references into packages.

Python:

	class Rectangle:
		def __init__(self, width, height):
			self.width = width
			self.height = height

		def get_area(self):
			return self.width * self.height

	rect = Rectangle(4,5)
	area = rect.get_area()

Java:

	public class Rectangle {
		private double width;
		private double height;

		public Rectangle(double width, double height) {
			this.width = width;
			this.height = height;
		}

		public double getArea() {
			return this.width * this.height;
		}

		public static void main(String[] args) {
			Rectangle rect = new Rectangle(4,5);
			double area = rect.getArea();
		}
	}

C++:

	#include <iostream>

	class Rectangle {
	private:
		double width;
		double height;

	public:
		Rectangle(double w, double h) {
			width = w;
			height = h;
		}
		double getArea() {
			return width * height;
		}
	};

	int main() {
		Rectangle rect(4,5);
		double area = rect.getArea();
		return 0;
	}

C:

	#include <stdio.h>
	
	typedef struct {
		double width;
		double height;
	} Rectangle;
			//Here we simulate OOP by passing the struct as a pointer
	double getArea(Rectangle* rect) {
		return rect->width * rect->height;
	}

	int main() {
		Rectangle rect = {4.0, 5.0};
		double area = getArea(&rect);
		return 0;
	}

PERL:

	package Rectangle;

	# Constructor
	sub new {
	    my $class = shift;
	    my $self = {
	        width  => shift,
	        height => shift,
	    };
	    # "Blessing" ties the hash reference to the Rectangle class
	    bless $self, $class;
	    return $self;
	}

	sub get_area {
	    my $self = shift; # The object itself is passed as the first argument
	    return $self->{width} * $self->{height};
	}

	my $rect = Rectangle->new(4, 5);
	my $area = $rect->get_area();

Conclusion:


As you can see in the code snippets, each language has both strengths and weaknesses and choosing the right language for the job is perhaps the first critical step when developing a project.

Python: Very readable and user friendly with built-in OOP, but can get caught up in debugging and long runtimes.

Java: A robust and highly structured system along with built-in OOP allows a wide variety of uses, but can be longer and more arduous than Python or PERL.

C++: Has great OOP and bridges the gap between Java and C beautifully, but can be difficult to grasp and master.

C: A foundational, procedural language, but it lacks some of the refinement of newer languages. No native OOP, for example.

PERL: Flexible and powerful for text manipulation allowing more "natural language" style coding, but OOP is handled awkwardly and it can be difficult to parse.
